# Product catalog — the 3 focus products

Only these three are in scope for the daily routine. Do not substitute other
catalog items unless the user explicitly asks.

Everything in the **Hard rules** column is a *factual* constraint. Getting one
wrong is a factual error, not a style note — it ships a claim the brand does not
make about its own product.

---

## Feather Knife

| | |
|---|---|
| **Price** | $99.90 |
| **Handle** | Rosewood |
| **Blade pattern** | **Laser-applied.** Never say hand-etched, hand-finished, or engraved. **Never describe the technique at all** — name the pattern, not how it got there. |
| **Availability** | ~500-unit limited drops, ~3-month restock |
| **Notion `Product` value** | `Feather` |
| **Primary persona** | JOHN (collector) |
| **Also runs as** | MIKE — NK222 "Return Feather Lunatic" is a Feather × MIKE US Winner. The repo `CLAUDE.md` lists Feather as JOHN-only; the corpus is broader. |

The scarcity is the mechanic. Hard production cap + real restock lead time is
the only urgency JOHN accepts — see `02-personas/john-collector.md`. Three of
the highest-ROAS evergreen concepts of 2026 are Feather scarcity plays:
NK139 "Feather Back In Stock" (2.36), NK130 "#5 Reasons Feather" (2.70),
NK133 "3 Months to Make" (1.62).

## BJORN Series Santoku

| | |
|---|---|
| **Blade** | Norse engravings |
| **Bolster** | Dragon-sculpted **brass** |
| **Handle** | Hand-carved wood |
| **Absolute rule** | **Never use the word "Japanese"** — not as origin, not as comparison, not as a shape reference. Santoku is a Japanese-origin knife shape and the brand never says so. |
| **Notion `Product` value** | `SANTOKU` |
| **Primary persona** | JOHN |

**Santoku is the clearest scaling opportunity on the board.** Four Santoku
concepts in the July 2026 book all beat the 1.94 video average — NK117 (2.42),
NKFD076 (2.69), NK167 (2.34) — on a product that had taken barely $13k of spend
all year, at the best ROAS of any major product (2.08).

Note NK117 is NK023's mechanic re-shot on Santoku: **1.77 → 2.42.** That is the
core play of this whole routine, proven on this exact product.

## LOKI Blackout Edition

| | |
|---|---|
| **Price** | $79.90 |
| **Steel** | High-carbon |
| **Handle** | Ebony |
| **Bottle opener** | Built into the **handle** — not the blade, not the spine. (The LOKI *Reaper* is the one with the opener notched into the blade. Do not mix them up.) |
| **Packaging** | Black branded box, magnetic closure |
| **What it is** | All-black remake of the #1-selling LOKI Viking Knife |
| **Notion `Product` value** | `LOKI Blackout` |
| **Personas** | MIKE (BBQ/grill self-buyer), SARAH (gift framing), general/deal-led for VANCE |

The bottle opener is the single most reliable surprise beat for MIKE — it is a
feature no competitor ad calls out and it lands squarely inside his world. See
NK306 "Yeah Guy" in `04-winning-briefs/` for the reference execution.

## Product facts that are load-bearing for products *outside* this routine

Kept here only so a cross-product line in a multi-product brief doesn't ship a
factual error. Do not build briefs around these.

| Product | Rule |
|---|---|
| RAGNAR Tiger Cleaver | **NOT full tang.** 10-inch, **leather** sheath. |
| LOKI Reaper | Opener notched **in the blade**. **No curved tip.** |
| Rolling Sharpener | Separate line. **Never** reference knives, knife names, grilling or BBQ. |

Brand-level claims ("100,000+ customers") work on any product.
**Never borrow another SKU's review count.**

## What is deliberately out of scope

The live `Product` select carries ~23 options — the ODIN set, VALHALLA,
RAGNAROK, Gunnar, Dragon Cleaver, Tiger Cleaver, LOKI Reaper, LOKI Berserker,
BJORN Utility, the Rolling Knife Sharpener, and `Multi`. The full persona set
carries 9 avatars including STEVE, DARIEN, DANA, DON and COLE.

None of those are part of this routine. If a rewrite seems to want one, that is
a signal the inspo ad was a poor match for the 3 focus products — pick a
different inspo rather than a different product.
