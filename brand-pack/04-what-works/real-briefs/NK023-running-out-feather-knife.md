**Offer:** NA (no B2G2/B2G1 — this predates the current Feather offer rule change).
**Persona:** Multi/Generalist tagged, but reads as John/Collector in voice.

## Key real facts confirmed by this script
- **"Only 500 of these exist"** / **"they only made 500 of them"** — a specific real production-run number, distinct from (and more concrete than) the "3-month restock cycle" detail found in NK130/NK133. Both are real, non-contradictory facts (a capped run of 500 units, restocked roughly every 3 months) — worth using together for maximum credibility, though prefer the restock-cadence framing as the current default (see `_index.md`).
- **"No restock. No waitlist."** — an explicit confirmation that, at least at the time this was written, Feather had no waitlist mechanic. Cross-check against current reality before reusing.
