# START HERE — NorthernKnife creative reference library

This is the reference library for the daily ad-rewriting routine described in
the repo root `CLAUDE.md`. Read this page, then read the process doc, then
write.

Brand: **NorthernKnife** (https://northernknife.com/) — hand-forged,
Viking-inspired knives.

## Reading order

1. **`05-process/creative-brief-process.md`** — the single most important file.
   Section C is the copy-voice rulebook. Section D/D0 is the exact live Notion
   video-brief template. Section E is product accuracy. Section F is the
   originality gate.
2. **`01-brand/product-catalog.md`** — the 3 focus products and their
   never-violate rules.
3. **`02-personas/`** — JOHN, MIKE, SARAH, VANCE. One file each.
4. **`03-copy/approved-copy.md`** — house proof stack, offer language, hook
   patterns, and the delete-on-sight list.
5. **`04-winning-briefs/`** — two complete real briefs copied out of the live
   Notion database, plus an index of every concept currently tagged a winner.

## The one rule that outranks the documents

**Where a document here conflicts with the real shipped ad corpus, the corpus
wins.** This is not a hedge — it is the standing instruction from the brand's
own performance review (`What's Worked YTD 2026`, Section 9). Several claims in
the persona pages are evidence-free or contradict the banned-jargon list. Those
specific conflicts are catalogued in the process doc, Section C.6.

Likewise, **the live Notion page beats the template transcribed in Section D.**
Andy edits the live template faster than any doc gets updated. Before writing a
batch, open the current default template page in the Video Brief Database and
diff it against Section D. The drift history is Section C.7.
