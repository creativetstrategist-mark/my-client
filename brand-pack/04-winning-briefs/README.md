## The core play

**Iterating a proven concept beats inventing one.** Three independent cases,
same result:

- NK117 is NK023's structure re-shot on Santoku: **1.77 → 2.42**
- NK120 is NKFD040 re-cut: **3.54 → 3.14** (at a fraction of the spend)
- NKEOFY005 is NKFD046 adapted for AU: **1.72 → 2.16**

This is exactly what the daily routine does — take a winning structure, rewrite
every word for a different product and persona. Watch NK023 and NK117 back to
back before writing.
