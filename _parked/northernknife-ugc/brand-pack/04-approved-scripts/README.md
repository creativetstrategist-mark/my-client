# Approved scripts

Reference material: scripts that shipped and performed.

## This folder is mostly redundant now

The Gen 2 system already tracks proven work better than a folder can:

- Each row in the `🎬 Creator Script Library` carries a **`Source winner`**
  naming the proven ad it was built from, with its real spend — e.g.
  *"NORTH_R2B8 V4. $118,539, ROAS 1.99, 2,121 purchases."*
- **`Mode`** records how far the adaptation went: `Verbatim iteration`,
  `Adapted`, or `From your UGC Script Library`.
- **`Status`** carries rows through to `Live` and `Retired`.

So the winners and their lineage live in the database. Use this folder only
for material that has nowhere else to go — a transcript of an outside ad, or
a script from before the library existed.

## How to use what's here

**Swipe the mechanic. Never the lines.** Take the hook pattern, the beat
order, where the offer sits, how proof is placed — then write every sentence
fresh. `Mode` says how close the structure may stay; it never licenses a
copied sentence. Process doc Section F.5.

## Naming

`<SCRIPT-ID>.md` where one exists, matching `ugc-scripts/`. For pre-library
material, a short descriptive slug plus the year.
