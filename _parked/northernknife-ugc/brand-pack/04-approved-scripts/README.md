# Approved scripts

Scripts that shipped and performed. Reference material.

## How to use this folder

**Swipe the mechanic. Never the lines.** Take the hook pattern, the beat
order, where the offer sits, how the proof is placed. Then write every
sentence fresh. A beat doing the identical job still gets new words —
process doc Section F.2 is the gate, and it applies to this folder as hard as
it applies to an outside reference ad.

## Naming

`YYYY-MM-DD-<product>-<persona>-<moment>.md` — same as `ugc-scripts/`.
Add a short results note at the top of each file when the numbers come in.
