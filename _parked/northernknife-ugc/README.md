# northernknife-ugc

UGC scripting routine for **NorthernKnife** (https://northernknife.com/) —
hand-forged, Viking-inspired knives.

Sibling repo to `my-client` (the daily ad-rewriting routine). That repo turns
TrendTrack winners into Notion video briefs. **This** repo turns a persona +
product + moment + offer into **creator-ready talking-head scripts** with full
iPhone shoot direction and a shared b-roll list.

- Start with `CLAUDE.md` — the hard rules.
- Then `brand-pack/START-HERE.md` — the reference library.
- The authoritative deliverable spec is
  `brand-pack/05-process/ugc-script-process.md`.
- Finished scripts land in `ugc-scripts/` and are logged in
  `ugc-scripts/processed-concept-log.md`.

## Status
